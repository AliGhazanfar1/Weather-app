# Weather App 🌤️

A simple weather application built using **HTML, CSS, and JavaScript** that fetches real-time weather information using the **OpenWeatherMap API**.

## Features

* Search weather by city name
* Display current temperature in Celsius
* Display humidity
* Display wind speed
* Dynamic weather icons
* Invalid city error handling
* Responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* OpenWeatherMap API

## How It Works

1. Enter the name of a city in the search box.
2. Click the search button.
3. The application sends a request to the OpenWeatherMap API.
4. Weather information is retrieved and displayed on the screen.
5. The weather icon changes according to the current weather condition.
6. If the city is invalid, an error message is displayed.

## API

This project uses the **OpenWeatherMap API** to retrieve weather data.

**API Documentation:**
https://openweathermap.org/api

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a city name.
5. Click the search button.
