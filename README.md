# Weather-app
A simple weather application built using HTML, CSS, and JavaScript that fetches real-time weather information using the OpenWeatherMap API.

Features
Search weather by city name
Display current temperature in Celsius
Display humidity
Display wind speed
Dynamic weather icons
Invalid city error handling
Responsive user interface
Technologies Used
HTML5
CSS3
JavaScript
OpenWeatherMap API

How It Works
Enter the name of a city in the search box.
Click the search button.
The application sends a request to the OpenWeatherMap API.
Weather information is retrieved and displayed on the screen.
The weather icon changes according to the current weather condition.
If the city is invalid, an error message is displayed.
API

This project uses the OpenWeatherMap API to retrieve weather data.

API Documentation:
https://openweathermap.org/api

How to Run
Clone this repository.
Open the project folder.
Open index.html in your browser.
Enter a city name.
Click the search button.
